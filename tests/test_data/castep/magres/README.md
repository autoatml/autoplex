# CASTEP magres reference data

`CASTEP_CRISTOBALITE_ALPHA` and `CASTEP_CRISTOBALITE_BETA` contain outputs of CASTEP 21.11
magres (NMR) calculations on α-cristobalite and ideal (C9) β-cristobalite. The structures are
taken from the dataset accompanying:

C. Ben Mahmoud, L. A. M. Rosset, J. R. Yates, V. L. Deringer, "Graph-neural-network predictions
of solid-state NMR parameters in silica from spherical tensor decomposition",
J. Chem. Phys. 163, 024118 (2025), https://doi.org/10.1063/5.0274240

Dataset (CC BY 4.0): https://doi.org/10.5281/zenodo.15775328

If you use these structures or data, please cite the paper and the dataset.
